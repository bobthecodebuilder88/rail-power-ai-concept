# 전철전력 관제 · AI 보조 (콘셉트 화면)

AI가 전철전력 관제를 돕는다면 화면이 어떤 모습일 수 있을지 휴몬랩이 그려 본 콘셉트 화면입니다.

- 노선·개소·설비·수치는 모두 가상입니다. 실제 시스템과 연결되어 있지 않고, 제어 기능이 없습니다.
- 장면 1: 급전선 지락으로 알람이 한꺼번에 들어올 때 AI가 같은 사건의 알람을 묶고, 고장점표정 결과 옆에 과거 표정 오차로 만든 참고 순회 범위를 보여 줍니다.
- 장면 2: 주변압기 권선 온도가 같은 부하·외기 조건의 과거 값보다 높게 나오는 것을 점검 후보로 올립니다.
- 장면 3: 급전 차단기 개방 시간이 같은 형식 차단기와 달리 조금씩 늘어나는 것을 점검 후보로 올립니다.

## 실행

```
npm install
npm run dev
npm test
npm run build
```
